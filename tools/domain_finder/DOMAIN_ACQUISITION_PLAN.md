## HOW THIS WORKS

**301 Redirect Domains** = Aged domains from defunct companies. You buy them, set up a 301 redirect to your main site. All their old backlinks (press, directories, industry sites) now pass authority to YOUR site. Users never see the old domain name. Cost: ~£5-8 each for .co.uk.

**Build-On Domains** = Keyword-rich domains you build an actual website on. These have no backlinks but match what people search for (e.g. "compare invoice finance"). You build content on them and they rank for those exact terms. Cost: ~£5-10 each.

**Sniping Domains** = High-value .com domains currently registered but expiring soon. You set up backorders so when they drop, you grab them. These are the big prizes — aged domains with massive backlink profiles from press coverage (BBC, FT, etc.). Cost: £20-5,000+ at auction.

# PART 4: THE SNIPING PLAN (Forward-Looking)

## How Domain Sniping Works

1. **Domain expires** — owner doesn't renew
2. **Grace period** (30-45 days) — owner can still renew at normal price
3. **Redemption period** (30 days) — owner can renew at premium price (~£100-300)
4. **Pending delete** (5 days) — domain queued for release
5. **Drop** — domain becomes available. Drop-catch services compete to grab it in milliseconds.
