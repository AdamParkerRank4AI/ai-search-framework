# APPENDIX: Domain Valuation Factors

| Factor | Why It Matters |
|--------|---------------|
| **Domain Age** | Older domains carry more trust signals with search engines |
| **Backlink Profile** | Links from authoritative sites (press, gov, edu) increase DA/DR |
| **Exact-Match Keyword** | "invoicefinance.com" ranks naturally for "invoice finance" |
| **Previous Site History** | Clean history (no spam/malware) preserves authority |
| **TLD** | .com is globally strongest; .co.uk strong for UK traffic |
| **Brand Recognition** | Former well-known brands may still have direct type-in traffic |
| **Search Volume** | Higher search volume = more organic traffic potential |
| **CPC / Lead Value** | Higher CPC keywords = more valuable lead gen revenue |

**Tools for Checking:**
- Domain Authority: [Moz Link Explorer](https://moz.com/link-explorer)
- Domain Rating: [Ahrefs](https://ahrefs.com)
- Trust/Citation Flow: [Majestic](https://majestic.com)
- Expired Domain Finder: [SpamZilla](https://www.spamzilla.io/)
- UK Expired Domains: [PowerfulDomains.co.uk](https://powerfuldomains.co.uk/)
- Expired Aggregator: [DomCop](https://www.domcop.com/)
- Backorder Service: [SnapNames](https://www.snapnames.com/) / [DropCatch](https://www.dropcatch.com/)
