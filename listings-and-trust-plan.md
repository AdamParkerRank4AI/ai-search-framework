- **MerchantHQ** (merchanthq.co.uk) — card terminals / payments

## Approach (read first)

- **Gemini-first.** Gemini / Google AI Overviews are grounded in Google's
  Knowledge Graph + sources Google already trusts. **Entity verification +
  trusted-source citation beats directory link volume.**
- **Finance is YMYL** — trust/authority signals outweigh links.
- **Most directories are nofollow.** Value = citation consistency + AI/entity
  validation + leads. The few dofollow ones are a bonus.
- **NAP rule:** identical Name / Address / Phone / description on *every*
  listing. Inconsistency = graph drift = lost trust.
- **Quality > volume.** ~80% of value sits in Tiers 1–3 + the schema.
- **Only register where you legitimately qualify** (esp. gov/regulated).
