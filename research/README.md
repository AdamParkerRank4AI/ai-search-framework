# Research index

Working research on the footprint-data-for-AI-search project. Five files, in roughly the order you'd want to read them.

## The pitch (what to send people)

- **ideas-and-questions-casual.md** — the brain-dump version, conversational tone, no em dashes. The one to forward to a friendly contact for a sanity check. ~5 minute read. Frames as ideas/questions/help-wanted, not as a finished plan.
- **proposal-for-vetting.md** — same content as the casual version but written as a more formal vet-able proposal. 16 numbered sections plus an executive summary. Use this version if the reader expects a structured document rather than a conversational note.

## The underlying research

- **plan-and-opportunity.md** — the full strategic plan. 16 sections covering concept, two-product structure (indoor map + AI grounding feed), staged go-to-market, four-layer business model, why we'd beat existing footfall players to AI platforms, six paths if data isn't openly buyable, prototype build plan with event model and tech stack, demand validation rhythm. The deepest single document.
- **maps-ai-search-qr.md** — original working notes from the early-stage thinking. Concept, tech stack, distribution, sign-up, advertising, location settings, offline behaviour, footfall capture options, AI-grounding thesis, inclusive design, competitive read. Reads like a scratchpad rather than a finished document.

## The working-area doc

- **data-sources-for-collation.md** — practical scratchpad for actually assembling a one-area test. Lists every accessible map base layer, mobile carrier flow vendor, footfall analytics product, SDK broker, vehicle probe data source, real-time tracking SDK, venue WiFi analytics, public/free signal, booking/event/commerce signal and IP geolocation service. Includes a procurement table by access pattern with rough costs and timelines, a step-by-step plan for building a working "show one area, real numbers, real day" demo for under low £k, market context (Markup investigation + post-2021 regulatory collapse) and a breakdown of the six different commercial models for "buying location data."

## Where things stand

The pitch is ready to forward. The research is ready for anyone vetting it to dig into. The next concrete step (per the plan documents) is the prototype: pick a venue, render OSM in Mapbox, capture intent events, layer Google Popular Times for sampled busyness, add Rank4AI entity records on each pin. Two to four weeks of one-developer work for a credible demo asset.
