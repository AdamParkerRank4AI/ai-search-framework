# Inspiration swipe file — AI SEO / AI search content on Instagram

The AI search niche moves week-to-week. Formats that worked in January will be played out by April. This file is the running log of what's working **right now** on Instagram in AI SEO / AI search / GEO / AEO content — so we can steal structures, not copy content.

**Cadence:** one 30-minute trawl per week. Friday morning works well — it catches the week's top posts before the weekend pile-up.

---

## The weekly trawl — what to do (30 minutes)

1. **Open each hashtag below in turn.** For each, scan "Top" posts for anything with unusually high engagement (>500 likes on a sub-5k account, >50 comments on anything).
2. **Screenshot the hook**, not the whole post. The first frame is where the idea lives.
3. **Log it below** in the table — one row per post you want to remember. Fill in: URL, format, what the hook is, why it worked, and what we could steal.
4. **Also check Saved tab of key accounts** (Aleyda, Exposure Ninja, Rise at Seven, Brainlabs) — they tag content they find noteworthy.
5. **Look at Reels' "Remix" counts** — if a reel has been remixed 20+ times it's a format worth studying.

## Patterns to watch for

Note these in the log when you see them — they tend to be early signals of a format that's about to go big.

- **"I asked ChatGPT..."** hook followed by a screen recording of the answer
- **Split-screen Google vs AI** comparisons
- **Before/after AI visibility** screenshots
- **Live audit** format — someone clicks through a real brand's site live
- **Outrage/hot take** — "SEO is dead", "Agencies are lying to you", etc.
- **Watch me build X in 60 seconds** — e.g. an llms.txt file, a schema stack
- **Nine-out-of-ten** style stat hooks
- **Day-in-the-life** founder content when the founder is a known name
- **"Things nobody tells you about X"** format
- **Comment-bait questions** — "which AI do you use? drop it below"

When a pattern appears in the log **three weeks in a row**, it's time to adapt it into one of our 7 formats. When a pattern stops appearing for three weeks, kill any of our content that still uses it.

## Using the swipe file

- Every Monday planning session, read the last 4 weeks of the log before picking hooks for the week's posts.
- When in doubt on a hook, check whether a similar format already got ≥3 entries in the log — if so, steal the structure. If not, it's untested and risky.
- Archive the file to `inspiration-archive-YYYY-Q[1-4].md` every quarter so the active file stays short.
